Bubble Sort

O(n²)

Bubble sort repeatedly steps through a list, compares each pair of neighboring items, and swaps them if they're in the wrong order. It repeats this pass over and over until no more swaps are needed, meaning the list is fully sorted.

The Assembly Line Analogy

Picture students lining up for morning assembly, arranged shortest to tallest, but instead of a teacher sorting them all at once, imagine sorting them by comparing just two neighbors at a time. You walk down the line: compare the first two students, and if the taller one is standing in front of the shorter one, they swap places. Move to the next pair, do the same thing. By the time you reach the end of the line, the tallest student has "bubbled" all the way to the back. Now you walk down the line again from the start, repeating the whole process, and each full pass pushes the next-tallest student into place. You keep doing full passes until one pass goes by with no swaps at all, that's how you know the whole line is finally sorted.

Where bubble sort shows up in real software

Bubble sort is rarely the fastest option in production systems, but it earns its place in a few specific situations.

Performance Trick

Nearly-Sorted Data Detection

Because bubble sort can stop the moment an entire pass makes zero swaps, it actually performs very well on data that's already almost sorted, a list that's just one or two items out of place gets fixed in a couple of passes, instead of always running the full worst-case number of passes like some other algorithms do regardless of how sorted the input already is.

Worked example: [1, 2, 4, 3, 5] — only one pair is out of place

Pass Swaps made Array after
1 1 (swapped 4 and 3) [1, 2, 3, 4, 5]
2 0 — already sorted [1, 2, 3, 4, 5]

For a list of 5 items, the worst case would need up to 4 full passes — but because this list was nearly sorted already, it finished in just 2. That's the early-exit check ("no swaps this pass") you already built into the visualizer above at work.

Education

Teaching & Visualization

Bubble sort's real claim to fame is as the standard first sorting algorithm taught to new programmers, its step-by-step comparisons are easy to trace by hand, which is exactly why this very page uses it to introduce sorting.

Constrained Systems

Simple & Embedded Systems

For very small, fixed-size datasets, bubble sort's dead-simple code sometimes wins over more complex algorithms, especially in memory-constrained embedded systems where simplicity matters more than raw speed.
