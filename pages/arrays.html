Array

O(1) Access

An array is a collection of items stored in a continuous block of memory, each one numbered starting from 0. Because every item has a fixed position, the computer can jump straight to any item instantly. It doesn't need to search for it.

The BRT Bus Analogy

Think of an array like numbered seats on a BRT bus. Seat 1, seat 2, seat 3 each seat has a fixed position, and if the conductor tells you "go sit in seat 4," you walk straight there without checking every other seat first. That's exactly how arrays work: every item has an index (its seat number), and the computer can jump directly to any index instantly — no searching required. The tradeoff is that adding or removing a seat in the middle means everyone behind has to shift over.

Where arrays show up in real software

Arrays are one of the most widely used data structures. Here are a few places you'll find them at work.

Graphics

Image & Pixel Storage

Every digital image is really a 2D array of pixel values. Editing software like Photoshop constantly accesses specific positions in that array to read or change a pixel's color — fast, direct access by position is exactly what arrays are built for.

Performance

Lookup Tables

When a value needs to be found instantly instead of calculated every time like a pre-computed multiplication table, or the internal storage behind a hash table — programs store the values in an array so any entry can be retrieved by index in constant time.

Foundations

Building Block for Other Structures

Many other data structures are commonly implemented using an array underneath including the others you just explored. A fixed block of ordered memory turns out to be a flexible foundation for building more specialized structures on top of.
