Data Structures

Queue

FIFO

A queue is a data structure that holds items in a single line, where you add new items at the back and remove items from the front. Unlike a stack, the first item added is the first one removed.

The ATM Queue Analogy

Think of a queue like people standing in line at an ATM. Whoever arrives first stands at the front, and whoever comes after joins the back of the line. When the machine is free, it's always the person at the front who gets served next — never someone who just walked in and pushed to the front. New arrivals always join at the rear. That's exactly how a queue works: the first item added is the first one removed. We call this FIFO — First In, First Out.

Where queues show up in real software

Anywhere tasks need to be handled fairly, in the order they arrived, you'll find a queue working behind the scenes.

Operating Systems

CPU Process Scheduling

In the simplest scheduling approach: First-Come, First-Served (FCFS) — the operating system queues up processes as they arrive and hands the CPU to whichever process has been waiting longest. A new process joins the rear of the queue; once the CPU finishes with the current process, it dequeues the next one from the front.

Worked example: P1 and P2 arrive, P1 runs, P3 arrives, P2 runs, P3 runs

Event Queue Running on CPU
P1 arrives [P1] —
P2 arrives [P1, P2] —
CPU dequeues next [P2] P1
P3 arrives [P2, P3] P1
P1 finishes, CPU dequeues next [P3] P2
P2 finishes, CPU dequeues next [] P3

Notice P3 has to wait its turn even though the CPU was free right when it arrived — that's the fairness FIFO guarantees: no cutting the line.

Everyday Software

Printer & Task Queues

When multiple print jobs, file uploads, or background tasks are submitted, they're lined up and processed in the order they arrived — the same job that's been waiting longest gets handled first.
